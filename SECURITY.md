## Reporting a Vulnerability

If you discover a security vulnerability within this repository, **do not open a public issue**. Public disclosures can expose users before a fix is available. 

Instead, please report it via one of the following methods:

* **Private Vulnerability Reporting:** Use GitHub's built-in private reporting feature located under the **Security** tab of this repository.
* **Direct Email:** Send details to your security contact email at `[Insert Email Here]`.

### What to Include in Your Report
To help us investigate and resolve the issue as quickly as possible, please provide:
* A description of the vulnerability and its potential impact.
* Step-by-step instructions or a proof-of-concept script to reproduce the issue.
* Any affected components, configurations, or agent tool integrations.

## Disclosure Policy

We follow coordinated vulnerability disclosure practices:
* **Acknowledgment:** You will receive an initial response to your report within **48 hours**.
* **Remediation:** We aim to release a patched version or mitigation guidance as soon as verified, depending on severity.
* **Credit:** Researchers who responsibly disclose valid vulnerabilities will be credited in our release notes (unless requested otherwise).
